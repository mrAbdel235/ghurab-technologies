# GHURAB Technologies

Site vitrine statique, prêt pour GitHub Pages.

## Fichiers
- `index.html`
- `style.css`
- `script.js`
- `favicon.svg`

## Publication avec GitHub Pages

1. Crée un dépôt public sur GitHub, par exemple `ghurab-technologies`.
2. Téléverse tous les fichiers à la racine du dépôt.
3. Va dans **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne la branche `main` et le dossier `/ (root)`.
6. Enregistre.
7. Après quelques instants, GitHub affichera l'adresse du site.

## Formulaire de contact
Le formulaire ouvre la messagerie de l'utilisateur avec un email prérempli vers `contact@ghurab.tech`.
Pour recevoir les messages sans logiciel de messagerie, il faudra ensuite connecter un service de formulaire.
